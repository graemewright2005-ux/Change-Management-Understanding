Project Management Monitoring and Control
This resource provides a summary of techniques that can be used to monitor and control projects.

Morphy, T. (N.D.). Project management monitoring and control techniques.


Access the resource here: https://www.stakeholdermap.com/project-management/project-monitoring-and-control.html

Questions:

The article introduces three areas to focus on when monitoring a project: the project plan, the project budget and the project team. What monitoring activities have you used previously that link to each of these categories?
A milestone slip chart is a tool that can be used to monitor the project plan. Would this be a useful document to incorporate into your monitoring activities? If so, how could you amend the chart presented to be more suited for use in your organisation?
Earned value analysis is used to monitor and control budgets. What type of projects in your organisation would this form of monitoring be most suited to?
Project status reports are advocated as an essential aspect of monitoring. What kind of status reports are used within your organisation?
Project Closure
This resource provides insight into the key activities that need to be completed to close a project.

Ray, S. (2019). 5 steps to project closure. ProjectManager, 13 Nov.


Access the resource here: https://www.projectmanager.com/blog/project-closure

Questions:

The article sets out five steps to be followed when closing a project. How many of these are implemented in your organisation when bringing a project to a close?
Archiving documents is an important step. What systems do you have in place to archive documents? Are these systems easy to navigate, or could they be improved?
A project closure checklist is provided at the link. Would this checklist be suitable for use when closing a project in your organisation? If not, how would you adapt it to be more suitable?
